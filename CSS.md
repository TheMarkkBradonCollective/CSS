# Customer Service Specialists

## The On-Demand Customer Experience & Business Intelligence Network

# Platform Identity

CSS is a marketplace connecting businesses with trained Customer Service Specialists who perform real-world evaluations, quality checks, field verification, mystery shopping, and operational reviews.

CSS Specialists provide businesses with unbiased information about what actually happens during customer interactions and daily operations.

---

# CSS App

The CSS mobile application operates as a two-sided marketplace.

## Client App

Businesses create missions and receive verified reports.

## Specialist App

Certified CSS Specialists find, accept, and complete missions.
